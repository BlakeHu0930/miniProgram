# 省点事 · 图片工具
原生微信小程序，JavaScript / WXML / WXSS，无 npm 运行时依赖，无服务器，无上传代码。

## 项目
`project.config.json` 位于本目录，代码在 `miniprogram/`。项目已配置用户提供的 AppID `wx94c47e43d954451b`，开发者权限与账号状态仍需微信开发者工具验证。正式预览、隐私接口声明与发布需要在微信公众平台配置真实 AppID，并按实际使用声明选择媒体、保存相册等隐私接口用途。不要在代码里放私钥。

## 已实现
- 首页采用三列紧凑图标网格，整块可点击；顺序：图片压缩（首位浅绿强调）、证件照尺寸（普通入口）、调整图片大小、图片转PDF；无一寸/两寸快捷按钮，已移除图片拼接。
- 图片转PDF：最多9张JPG/PNG，每图一页，删除/补选/上移/下移，A4留白或跟随图片比例；自定义文件名、文档预览/系统导出菜单、微信分享。逐张编码与流式写文件，输出图片长边≤2048、≤300万像素，JPEG质量0.9，PNG透明区转白底，PDF上限40MiB。
- PDF预览/分享使用微信原生能力，保存到文件等菜单以设备与微信版本为准，不含OCR或可搜索文字。退出工具清理PDF，需先导出。
- 调整尺寸：自定像素、比例锁定/独立宽高、25%/50%/75%/100%缩放；原图/3:2/16:9/9:16/1:1比例裁剪。
- 证件照：一寸295×413、两寸413×579、小两寸413×531，支持拖动/双指/滑杆缩放构图、重置、预览与保存。毫米按300 DPI换算，仅作参考；不修改DPI元数据，不含换底色与人像合规检测。
- 尺寸输出严格按输入执行，超出4096最长边或800万像素时拒绝，不自动改变目标值。PNG保留透明。
- 首页、参数页、结果页，沿用批准的雾白/青绿风格。
- 9 张选择、删除补选；JPG/PNG，500KB 默认，200KB/1MB/自定义、均衡。
- 顺序 Canvas 导出，实际读取文件字节数；有界质量搜索后等比缩小，失败不阻断整批。
- PNG 默认保透明，可经用户确认允许白底JPG。GIF等非JPG/PNG格式拒绝。
- 已符合目标、变大保原图、未达标提示、失败重试、原图/输出预览、单张/批量保存、拒绝权限设置引导。
- 本地临时输出清理、不修改输入文件，卸载页面后停止后续任务。

## 明确限制
- 输入上限30MiB/4000万像素；输出上限最长边4096且800万像素。避免手机内存峰值；Canvas解码仍占内存。
- PNG压缩主要依靠缩尺寸，无法保证任意极小目标与可读性同时满足。
- 已通过微信开发者工具编译及合成图片Canvas压缩测试。真实选图被隐私协议未声明阻塞（errno112）；相册保存仅模拟接口验证。EXIF旋转/镜像与大图内存须真机验证。
- PNG逐块读取头部识别APNG并拒绝，GIF由图片格式检查拒绝；文件读写API兼容性仍须微信测试。
- 临时文件不作为历史记录，退出后需重新选择。
